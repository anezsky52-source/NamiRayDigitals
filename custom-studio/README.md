Subfolder app inside the existing public NamiRayDigitals repository.

## Open locally or on GitHub Pages
If GitHub Pages is enabled for this repository, the app can be opened at:

`https://anezsky52-source.github.io/NamiRayDigitals/custom-studio/`

This address is a predicted Pages URL and will work only after Pages is enabled and the site finishes publishing.

## Included
- Idea Studio for project concepts and genre suggestions
- Character DNA prompt builder
- Environment prompt builder
- Storyboard outline builder
- Image/video prompt builder
- Social media caption and hashtag helper
- Local project archive with JSON import/export

## Important limitations
This is a static, browser-based creative planning and prompt-writing tool. It does not generate images or videos itself and does not call an AI model. Projects are stored in the current browser's local storage; export JSON to back them up.

No API key is required for the local features.
