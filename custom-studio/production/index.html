Production rules

  • Character DNA menjadi sumber identitas utama.
  • Setiap scene mewarisi kondisi scene sebelumnya.
  • Kostum berubah hanya jika ada event pergantian.
  • Suara memakai profil dan voice reference tetap.
  • Render pendek per scene, lalu rakit di editor video.

Target 30 menit dibagi menjadi scene pendek agar lebih mudah dikendalikan dan diperiksa.
